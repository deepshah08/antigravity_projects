# throw and throws in Java - GeeksforGeeks

Exception handling in Java helps manage runtime errors and prevents the program from crashing, allowing the normal flow of the application to continue. Java provides specific keywords to handle and manage exceptions effectively.throw is used to explicitly throw an exception. throws is used to declare exceptions in a method signature.throw KeywordThe throw keyword in Java is used to explicitly throw an exception from a method or any block of code. We can throw either checked or unchecked exception. The throw keyword is mainly used to throw custom exceptions. Written inside a method or block. Stops program execution immediately after execution.Syntax:throw new ExceptionName("message");Example: This example demonstrates where an exception is thrown, caught and rethrown inside a method.
            Java

    class Geeks {
    static void fun()
    {
        try {
            throw new NullPointerException("demo");
        }
        catch (NullPointerException e) {
            System.out.println("Caught inside fun().");
            throw e;     // rethrowing the exception
        }
    }

    public static void main(String args[])
    {
        try {
            fun();
        }
        catch (NullPointerException e) {
            System.out.println("Caught in main.");
        }
    }
}

OutputCaught inside fun().
Caught in main.
Explanation: The above example demonstrates the use of the throw keyword to explicitly throw a NullPointerException. The exception is caught inside the fun() method and rethrown, where it is then caught in the main() method.Example: Throwing an arithmetic exception
            Java

    class Geeks {
    public static void main(String[] args){
        int numerator = 1;
        int denominator = 0;

        if (denominator == 0) {
            // Manually throw an ArithmeticException
            throw new ArithmeticException("Cannot divide by zero");
        } else {
            System.out.println(numerator / denominator);
        }
    }
}

Output:Hangup (SIGHUP)Exception in thread "main" java.lang.ArithmeticException: Cannot divide by zero at Geeks.main(Geeks.java:9)Explanation: The above example demonstrates an exception using throw, where an ArithmeticException is explicitly thrown due to division by zero.throws Keywordthrows is a keyword in Java that is used in the signature of a method to indicate that this method might throw one of the listed type exceptions. The caller to these methods has to handle the exception using a try-catch block. Declares possible exceptions. Mainly used with checked exceptions.Syntax:returnType methodName() throws ExceptionNameExample 1: Unhandled Checked Exception
            Java

    class Geeks {
    public static void main(String[] args)
    {
        Thread.sleep(10000);
        System.out.println("Hello Geeks");
    }
}

Output:error: unreported exception InterruptedException; must be caught or declared to be thrownExplanation: Thread.sleep() declares that it may throw an InterruptedException, which is a checked exception. Therefore, the compiler requires the exception to be either handled using a try-catch block or declared using throws. Since the program does neither, it results in a compilation error.Example 2: Declaring an Exception Using throws
            Java

    class Geeks {
    public static void main(String[] args)
        throws InterruptedException
    {
        Thread.sleep(10000);
        System.out.println("Hello Geeks");
    }
}

Output:Hello GeeksExplanation: In this example, throws InterruptedException declares that the main() method may throw an InterruptedException. The throws keyword does not handle the exception; it passes the responsibility for handling or further declaring it to the caller. If no interruption occurs while the thread is sleeping, the program prints Hello Geeks.Example 3: Declaring and Throwing an Exception
            Java

    class Geeks {

    static void fun() throws IllegalAccessException
    {
        System.out.println("Inside fun(). ");
        throw new IllegalAccessException("demo");
    }

    public static void main(String args[])
    {
        try {
            fun();
        }
        catch (IllegalAccessException e) {
            System.out.println("Caught in main.");
        }
    }
}

OutputInside fun(). 
Caught in main.
Explanation: The fun() method declares IllegalAccessException using throws and explicitly throws it using throw.
