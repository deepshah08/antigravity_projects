# Creating First Java Application in IntelliJ IDEA - GeeksforGeeks

IntelliJ IDEA is one of the most popular Integrated Development Environments (IDE) used for Java development. It provides features like code completion, debugging, refactoring, and project management that make Java programming easier and faster. IntelliJ IDEA supports programming languages such as Java, Kotlin, Scala, and Groovy.Provides smart code completion and debugging tools. Helps in project management and JAR file creation. Available for Windows, Linux, and macOS platforms.ProcedureStart a project Create a package and Java class Write and run the Java program Package the project into a JAR file Configure the JAR application Execute the JAR fileStep-by-Step Implementation of First Java ApplicationStep 1: Start a New ProjectOpen IntelliJ IDEA. Click on New Project from the welcome screen. Name the project as 'GeeksForGeeks' (you can choose any name), and then clicks finish.Step 2: Create Package and Java ClassOn the left-hand side of the project window, select src -> new -> java classEnter the package and class name: GeeksForGeeks.gfgStep 3: Write the Java ProgramWrite the following Java program inside the class file:Example: Java demo program to print message on the console
            Java

    import java.io.*;

// Class
public class Geeksforgeeks {

    // Main driver method
    public static void main(String[] args)
    {
        // Print and display on the console after
        // successful compilation and execution
        System.out.println(
            "This is my first project in java");
    }
}

Step 4: Run the Java ProgramClick the Run button present at the top-right corner of IntelliJ IDEA. The output will appear in the console window.After writing the above code you may check if it is finishing with exit code '0' or not.Step 5: Package the Project into JAR FileGo to: File -> Project Structure -> ArtifactsClick on the addition sign(+) as you can see in the following image.Step 6: Build the ArtifactNavigate to: Build -> Build ArtifactsStep 7: Configure JAR ApplicationSelect Edit Configurations from the toolbar. Click the + icon and choose JAR Application.Choose the output directory for the .jar file.Select GeeksForGeeks : jar from the menu and press OK.Step 8: Execute the JAR FileSelect the JAR configuration from the toolbar. Click Run.
