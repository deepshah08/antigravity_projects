# Java URL Class - GeeksforGeeks

The URL class in the java.net package represents a Uniform Resource Locator, which identifies the location of a resource on the internet. It provides methods to access URL components and open a connection to the resource.Provides access to components such as the protocol, host, port, path, and query.Enables connections to resources through supported protocols, such as HTTP, HTTPS, and FTP.Components of a URLA URL can have many forms. The most general however follows a three-component system as proposed below: Its main components are:ComponentExampleDescriptionProtocol/SchemehttpsSpecifies how the resource is accessedHostwww.example.comIdentifies the server that hosts the resourcePort443Identifies the network port used for communicationPath/products/searchIdentifies the resource location on the serverQueryq=javaContains parameters passed after ?FragmentresultsIdentifies a specific section after URL Class The URL class is a core Java networking class used to access internet-based resources.It can point to static files, dynamic content, and APIsProvides constructors to create URL objectsOffers methods to extract different parts of a URLConstructors of URL class1. URL(String address): It creates a URL object from the specified String.URL url = new URL("https://www.example.com/");2. URL(String protocol, String host, String file): Creates a URL object from the specified protocol, host, and file name.    URL url = new URL("http", "www.example.com", "/path/to/resource");3. URL(String protocol, String host, int port, String file): Creates a URL object from protocol, host, port, and file name.URL url = new URL("https", "www.example.com", 443, "/path/to/resource");4. URL(URL context, String spec): Creates a URL object by parsing the given spec in the given context. URL baseUrl = new URL("https://www.example.com/");URL relativeUrl = new URL(baseUrl, "/path/to/resource");5. URL(String protocol, String host, int port, String file, URLStreamHandler handler): Creates a URL object from the specified protocol, host, port number, file, and handler.URL url = new URL("http", "www.example.com", 80, "/path/to/resource", new MyCustomHandler());6. URL(URL context, String spec, URLStreamHandler handler): Creates a URL by parsing the given spec with the specified handler within a specified context.URL baseUrl = new URL("https://www.example.com/");URL relativeUrl = new URL(baseUrl, "/path/to/resource", new MyCustomHandler());Example: Program to demonstrate the working of URL.
            Java

    import java.net.URI;
import java.net.URL;

public class Geeks {

    public static void main(String[] args) throws Exception
    {

        URL u1
            = URI.create("https://www.google.co.in/?gfe_rd=cr&ei=ptYq"
                     + "WK26I4fT8gfth6CACg#q=geeks+for+geeks+java").toURL();

        URL u2 = URI.create("http://www.geeksforgeeks.org/"
                            + "jvm-works-jvm-architecture/")
                     .toURL();

        URL u3
            = URI.create("https://www.google.co.in/search"
                     + "?q=gnu&rlz=1C1CHZL_enIN714IN715"
                     + "&oq=gnu&sourceid=chrome"
                     + "&ie=UTF-8#q=geeks+for+geeks+java")
                  .toURL();

        System.out.println(u1);
        System.out.println(u2);

        System.out.println(
            "\nDifferent components of URL3:");

        System.out.println("Protocol: " + u3.getProtocol());

        System.out.println("Hostname: " + u3.getHost());

        System.out.println("Default port: "
                           + u3.getDefaultPort());

        System.out.println("Query: " + u3.getQuery());

        System.out.println("Path: " + u3.getPath());

        System.out.println("File: " + u3.getFile());

        System.out.println("Reference: " + u3.getRef());
    }
}
