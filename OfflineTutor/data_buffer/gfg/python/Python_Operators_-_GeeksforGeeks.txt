            Python

    a = 15

Ternary OperatorTernary operators also known as conditional expressions are operators that evaluate something based on a condition being true or false. It was added to Python in version 2.5. It simply allows testing a condition in a single line replacing the multiline if-else, making the code compact.Syntax :  [on_true] if [expression] else [on_false] 
            Python

    a, b = 10, 20
min = a if a < b else b

print(min)

Output10
