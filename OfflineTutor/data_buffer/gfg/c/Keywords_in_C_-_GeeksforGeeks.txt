# Keywords in C - GeeksforGeeks

C keywords are reserved words that have predefined meanings recognized by the compiler. They form the basic building blocks of the C language and cannot be used as identifiers such as variable names, function names, or structure names.Have predefined meanings and form part of the C language syntax.
