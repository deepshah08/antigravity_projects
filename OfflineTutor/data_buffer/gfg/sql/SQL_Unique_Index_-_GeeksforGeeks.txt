# SQL Unique Index - GeeksforGeeks

A SQL Unique Index enforces uniqueness by ensuring that no duplicate values exist in specified column(s), helping maintain data integrity. It is widely used to prevent duplicate entries and keep database data consistent and reliable. It improves query performance by speeding up data retrieval.SyntaxCREATE UNIQUE INDEX index_name
ON table_name (column1, column2, ..., columnN);index_name: The name of the unique index.table_name: The name of the table where the index will be created.column1, column2, ..., columnN: The columns on which the unique index is being applied.Examples employees table is created to demonstrate how unique indexes enforce uniqueness on specific columns.Example 1: Creating a Unique Index on a Single ColumnThis example creates a unique index on the NAME column to prevent duplicate names in the employees table.
