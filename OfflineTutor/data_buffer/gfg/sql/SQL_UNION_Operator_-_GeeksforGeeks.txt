# SQL UNION Operator - GeeksforGeeks

The SQL UNION operator is used to combine the result sets of two or more SELECT queries into a single output. It removes duplicate rows and returns only unique records from all combined queries.UNION ALL includes all rows, even duplicates.Queries must have matching columns and data types.Helpful for combining data from different sources.Example: First, we create a demo SQL database and tables, on which we will use the UNION Operator command.Table1Table2Query:SELECT city FROM Table1UNIONSELECT city FROM Table2;Output: Syntax:SELECT column_name FROM table1UNIONSELECT column_name FROM table2;Examples of SQL UNION Let's look at an example of UNION operator in SQL to understand it better.
