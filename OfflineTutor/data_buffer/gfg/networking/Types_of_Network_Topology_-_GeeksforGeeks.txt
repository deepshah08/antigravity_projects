# Types of Network Topology - GeeksforGeeks

Network topology is the arrangement of devices (nodes) and connections (links) in a computer network. It shows how devices are connected and how data flows between them.Physical Topology: Actual arrangement of devices and cables.Logical Topology: How data flows between devices.Point-to-Point  TopologyIn point-to-point topology, two devices are connected directly to each other using a dedicated link. Only two devices communicate through the connection.  Data can be transferred directly between the two devices. Example: A direct connection between two routers.Point to Point TopologyMesh TopologyIn mesh topology, devices are connected to several other devices through separate links. Data can take different paths to reach its destination.  If one link fails, another link can be used for communication. Example: Mesh networks used in wireless home or office networks.MeshStar TopologyIn star topology, all devices are connected to a central device, usually a switch. All communication between devices passes through the central device.  Adding or removing a device does not affect the other connections. Example: Computers connected to a switch in an office LAN.Star TopologyBus Topology In bus topology, all devices share a single main cable called the backbone. Data travels along the main cable and is received by the intended device.  It uses less cabling compared with some other topologies. Example: Traditional Ethernet networks that used a shared coaxial cable.Bus TopologyRing Topology In ring topology, each device is connected to two other devices, forming a ring. Data moves from one device to the next around the ring.  Devices take turns transmitting data in networks that use token passing. Example: Token Ring networks.Ring TopologyTree Topology In tree topology, devices are connected in a hierarchical structure, forming different branches. It combines the features of star and hierarchical network structures.  New devices or branches can be added as the network grows. Example: A large organization's network where different departments have separate network segments connected to a main network.Tree TopologyHybrid TopologyIn hybrid topology, two or more different network topologies are combined in the same network. Different parts of the network can use different topologies.  The design can be changed according to the network's requirements. Example: A university network that uses star topology within buildings and connects those buildings using another topology.Hybrid Topology
