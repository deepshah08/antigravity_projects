# TypeScript Tutorial - GeeksforGeeks

TypeScript is a superset of JavaScript that adds extra features like static typing, interfaces, enums, and more. Essentially, TypeScript is JavaScript with additional syntax for defining types, making it a powerful tool for building scalable and maintainable applications.Static typing allows you to define variable types and helps catch errors before running the code.TypeScript is compiled into JavaScript, ensuring it works in all JavaScript environments.It’s widely used for web development on both the client and server sides.Developed by Microsoft, TypeScript is trusted by companies like Google, Slack, Airbnb, and Asana.Note: We are currently using TypeScript 5.0, which brings faster performance and new features.
