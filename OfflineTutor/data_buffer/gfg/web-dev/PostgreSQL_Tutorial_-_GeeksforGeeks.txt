# PostgreSQL Tutorial - GeeksforGeeks

PostgreSQL is a free and open-source database management system used to store, organize and manage data efficiently. It is one of the most popular databases because it is reliable, secure and can handle large amounts of data.Supports SQL queries to store, retrieve and manage data.Allows transactions to keep data accurate and consistent.Supports JSON and JSONB data for modern applications.Uses Multi-Version Concurrency Control (MVCC) to allow many users to work with the database at the same time.Can be extended with custom data types, functions and extensions.
