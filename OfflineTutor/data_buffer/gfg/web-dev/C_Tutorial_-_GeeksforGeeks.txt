# C# Tutorial - GeeksforGeeks

C# (pronounced C-sharp) is a modern, object-oriented programming language developed by Microsoft. It is widely used to build Windows applications, web applications, mobile apps, games (using Unity), and enterprise software systems.C# runs on the .NET runtime, which allows applications to execute on multiple platforms including Windows, macOS, and Linux with .NET Core and later versions of .NET. Its syntax is similar to other C-based languages like C++ and Java.Hello World Program
            C#

    using System;

class HelloWorldProgram
{
    static void Main(string[] args)
    {
        Console.WriteLine("Hello, World!");
    }
}

OutputHello, World!
