# Minimize Cash Flow - GeeksforGeeks

Given n friends and a 2D array transaction[][], where transaction[i][j] is the amount of money friend i owes to friend j, find a settlement of all the debts with the minimum total cash flow. A settlement is a matrix result[][], where result[i][j] is the amount friend i pays to friend j after settling. It is valid if:Every friend keeps the same net balance (money received minus money paid) as in transaction[][].All entries are non-negative and result[i][i] = 0.The total cash flow is the sum of all the entries of result[][], and the number of transactions does not matter. Many valid settlements can exist, and any with the minimum total cash flow is accepted. In the examples, the output is the total cash flow of the returned settlement.Examples:Input: transaction[][] = [[0, 100, 0], [0, 0, 200], [0, 0, 0]]Output: 200Explanation: The net balances of friends 0, 1 and 2 are -100, -100 and +200. The settlement [[0, 0, 100], [0, 0, 100], [0, 0, 0]] has a total cash flow of 200, which is less than the original 300.Input: transaction[][] = [[0, 0, 50, 0], [0, 0, 0, 30], [0, 0, 0, 10], [0, 0, 0, 0]]Output: 80Explanation: The net balances of friends 0 to 3 are -50, -30, +40 and +40. The settlement [[0, 0, 40, 10], [0, 0, 0, 30], [0, 0, 0, 0], [0, 0, 0, 0]] has a total cash flow of 80, which is the minimum. Another valid settlement is [[0, 0, 20, 30], [0, 0, 20, 10], [0, 0, 0, 0], [0, 0, 0, 0]], also with a total cash flow of 80.Input: transaction[][] = [[0, 100, 0], [0, 0, 100], [100, 0, 0]]Output: 0Explanation: The debts form a cycle: friend 0 owes 100 to friend 1, friend 1 owes 100 to friend 2, and friend 2 owes 100 to friend 0. The net balance of every friend is 0, so the settlement [[0, 0, 0], [0, 0, 0], [0, 0, 0]] is valid, and its total cash flow is 0.Try It YourselfTable of Content[Naive Approach] Removing Middlemen One by One - O(n^3) Time and O(n^2) Space[Expected Approach] Greedy with Net Balances - O(n^2) Time and O(n^2) Space[Naive Approach] Removing Middlemen One by One - O(n^3) Time and O(n^2) SpaceIf friend i owes money to friend k, and k owes money to friend j, then k is just a middleman. The money can go from i to j directly, which reduces the total cash flow. We remove the middlemen one friend at a time, working on a copy of the matrix.For a friend k, take every pair (i, j) where i owes k and k owes j, and move the common amount min(i's debt to k, k's debt to j) directly from i to j.If i and j are the same friend, the money goes in a circle, so it cancels completely.After this step, k either only pays or only receives, never both, and the later steps do not change this.After all friends are processed, everyone is only a payer or only a receiver, so no money passes through a middleman, and the total cash flow is the minimum.Working of the Approach:Create a copy result[][] of transaction[][], and set result[i][i] = 0 for every friend, since a friend cannot owe money to himself.For every friend k from 0 to n - 1, check every pair (i, j) of friends.If result[i][k] > 0 and result[k][j] > 0, then i owes k and k owes j, so compute amount = min(result[i][k], result[k][j]).Subtract amount from both result[i][k] and result[k][j], since k no longer passes this money on.If i != j, add amount to result[i][j], since i now pays j directly. If i == j, add nothing, because the money returns to i and cancels.After all friends are processed, return result[][].Illustration:Consider transaction[][] = [[0, 100, 0], [0, 0, 100], [100, 0, 0]]. Friend 0 owes 100 to friend 1, friend 1 owes 100 to friend 2, and friend 2 owes 100 to friend 0.k = 0: friend 2 owes 100 to friend 0, and friend 0 owes 100 to friend 1, so friend 0 is a middleman. The amount is min(100, 100) = 100. We subtract it from both debts, so friend 2 now pays friend 1 directly, and result[2][1] = 100.The matrix now has only two debts: friend 1 owes 100 to friend 2, and friend 2 owes 100 to friend 1.k = 1: friend 2 owes 100 to friend 1, and friend 1 owes 100 to friend 2. The amount is 100. We subtract it from both debts. Here i = j = 2, so nothing is added, because the money returns to friend 2 and cancels.k = 2: no friend owes anything now, so nothing changes.The result is [[0, 0, 0], [0, 0, 0], [0, 0, 0]], and the total cash flow is 0.

    #include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

vector<vector<int>> minCashFlow(vector<vector<int>>& transaction) {
    int n = transaction.size();

    // work on a copy, and a friend cannot owe money to himself
    vector<vector<int>> result = transaction;
    for (int i = 0; i < n; i++)
        result[i][i] = 0;

    // remove every friend k as a middleman, one by one
    for (int k = 0; k < n; k++) {
        for (int i = 0; i < n; i++) {

            // i does not owe anything to k, so k is not a middleman for i
            if (result[i][k] == 0)
                continue;

            for (int j = 0; j < n; j++) {

                // i owes k and k owes j, so i can pay j directly
                if (result[i][k] > 0 && result[k][j] > 0) {
                    int amount = min(result[i][k], result[k][j]);
                    result[i][k] -= amount;
                    result[k][j] -= amount;

                    // if i and j are the same friend, the money goes in a circle and cancels
                    if (i != j)
                        result[i][j] += amount;
                }
            }
        }
    }

    return result;
}

int main() {
    vector<vector<int>> transaction = {{0, 100, 0}, {0, 0, 100}, {100, 0, 0}};
    vector<vector<int>> result = minCashFlow(transaction);

    // total cash flow is the sum of all the entries of the settlement
    long long total = 0;
    for (auto& row : result)
        for (int x : row)
            total += x;

    cout << total << endl;

    return 0;
}

    #include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// Time Complexity: O(n^2), Auxiliary Space: O(n^2)
vector<vector<int>> minCashFlow(vector<vector<int>>& transaction) {
    int n = transaction.size();

    // net balance of a friend is the money received minus the money paid
    vector<int> net(n, 0);
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++)
            net[i] += transaction[j][i] - transaction[i][j];
    }

    vector<vector<int>> result(n, vector<int>(n, 0));

    while (true) {

        // friend who must pay the most and friend who must receive the most
        int debtor = min_element(net.begin(), net.end()) - net.begin();
        int creditor = max_element(net.begin(), net.end()) - net.begin();

        // balances add up to zero, so the smallest balance is 0 only when everything is settled
        if (net[debtor] == 0)
            break;

        // at least one of the two friends is fully settled in every step
        int amount = min(-net[debtor], net[creditor]);
        result[debtor][creditor] = amount;
        net[debtor] += amount;
        net[creditor] -= amount;
    }

    return result;
}

int main() {
    vector<vector<int>> transaction = {{0, 0, 50, 0}, {0, 0, 0, 30}, {0, 0, 0, 10}, {0, 0, 0, 0}};
    vector<vector<int>> result = minCashFlow(transaction);

    // total cash flow is the sum of all the entries of the settlement
    long long total = 0;
    for (auto& row : result)
        for (int x : row)
            total += x;

    cout << total << endl;

    return 0;
}

    class GFG {

    // Time Complexity: O(n^2), Auxiliary Space: O(n^2)
    static int[][] minCashFlow(int[][] transaction) {
        int n = transaction.length;

        // net balance of a friend is the money received minus the money paid
        int[] net = new int[n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++)
                net[i] += transaction[j][i] - transaction[i][j];
        }

        int[][] result = new int[n][n];

        while (true) {

            // friend who must pay the most and friend who must receive the most
            int debtor = 0, creditor = 0;
            for (int i = 1; i < n; i++) {
                if (net[i] < net[debtor])
                    debtor = i;
                if (net[i] > net[creditor])
                    creditor = i;
            }

            // balances add up to zero, so the smallest balance is 0 only when everything is settled
            if (net[debtor] == 0)
                break;

            // at least one of the two friends is fully settled in every step
            int amount = Math.min(-net[debtor], net[creditor]);
            result[debtor][creditor] = amount;
            net[debtor] += amount;
            net[creditor] -= amount;
        }

        return result;
    }

    public static void main(String[] args) {
        int[][] transaction = {{0, 0, 50, 0}, {0, 0, 0, 30}, {0, 0, 0, 10}, {0, 0, 0, 0}};

    # net balance of a friend is the money received minus the money paid

    for i in range(n):
        for j in range(n):
