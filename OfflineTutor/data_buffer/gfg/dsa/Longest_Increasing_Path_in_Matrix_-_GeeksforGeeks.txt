# Longest Increasing Path in Matrix - GeeksforGeeks

Given a matrix with n rows and m columns, find the length of the longest path such that:The path can start and end at any cell.A cell cannot be visited more than once.The values in path are strictly increasing. From each cell, you can move left, right, up, or down.Diagonal moves and moves outside the matrix are not allowed.Examples: Input: n = 3, m = 3, matrix[][] = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]Output: 5Explanation: One such path is 1 -> 2 -> 3 -> 6 -> 9, where each number is strictly greater than the previous. Input: n = 3, m = 3, matrix[][] = [[3, 4, 5], [6, 2, 6], [2, 2, 1]]Output: 4Explanation: One of the longest increasing paths is 3 -> 4 -> 5 -> 6. Input: n = 2, m = 2, matrix[][] = [[1, 1], [1, 1]]Output: 1Explanation: There can at most one vertex as all vertices are same.Try It YourselfTable of Content[Naive Approach] Using Recursion - O(4^(m * n)) Time and O(m * n) Space[Expected Approach - 1] Using Memoization(DP) - O(m * n) Time and O(m * n) Space[Expected Approach - 2] Using Kahn's algorithm - O(m * n) Time and O(m * n) Space[Naive Approach] Using Recursion - O(4^(m * n)) Time and O(m * n) SpaceThe idea is to start a path from every cell and recursively explore all four directions. We move only to a neighboring cell whose value is greater than the current cell, and keep track of the maximum path length found.Traverse every cell and consider it as the starting point.Recursively check all four possible directions from the current cell.Move to a neighboring cell only if it is within bounds and has a greater value.Compute the longest increasing path starting from each valid neighboring cell.Add the current cell to the path and update the maximum length.Return the maximum path length obtained from all cells.

    #include <bits/stdc++.h>
using namespace std;

// Function to check whether the cell is valid and
// its value is greater than the previous cell.
bool validCell(int i, int j, vector<vector<int>> &matrix, int n, int m, int prev)
{
    return (i >= 0 && i < n && j >= 0 && j < m && matrix[i][j] > prev);
}

// Recursive function to find the longest increasing path
// starting from the cell (i, j).
int pathRecur(int i, int j, vector<vector<int>> &matrix, int n, int m)
{
    // Include the current cell in the path.
    int ans = 1;

    // Directions for moving down, up, right and left.
    vector<vector<int>> dir = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

    // Try moving in all four directions.
    for (auto d : dir)
    {
        int x = i + d[0];
        int y = j + d[1];

        // Move only if the next cell is valid and
        // has a greater value than the current cell.
        if (validCell(x, y, matrix, n, m, matrix[i][j]))
        {
            // Find the longest path from the next cell.
            ans = max(ans, 1 + pathRecur(x, y, matrix, n, m));
        }
    }

    return ans;
}

// Function to find the length of the longest
// strictly increasing path in the matrix.
int longIncPath(vector<vector<int>> &matrix, int n, int m)
{
    int ans = 0;

    // Start a path from every cell.
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            // Find the longest increasing path starting
            // from the current cell.
            ans = max(ans, pathRecur(i, j, matrix, n, m));
        }
    }

    return ans;
}

int main()
{
    vector<vector<int>> matrix = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};

    int n = matrix.size();
    int m = matrix[0].size();

    cout << longIncPath(matrix, n, m) << endl;

    return 0;
}

    #include <bits/stdc++.h>
using namespace std;

// Function to find the longest increasing path in a matrix
int longIncPath(vector<vector<int>> &matrix, int n, int m)
{
    // Directions for moving right, down, left and up.
    vector<pair<int, int>> dir = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};

    // degree[i][j] stores the number of smaller
    // neighboring cells for cell (i, j).
    vector<vector<int>> degree(n, vector<int>(m, 0));

    // Calculate the degree of every cell.
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            for (auto d : dir)
            {
                int x = i + d.first;
                int y = j + d.second;

                // Count the neighboring cells having
                // a smaller value than the current cell.
