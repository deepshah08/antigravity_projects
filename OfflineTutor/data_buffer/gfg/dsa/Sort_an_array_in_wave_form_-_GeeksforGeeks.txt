# Sort an array in wave form - GeeksforGeeks

Given an array arr[] of integers sorted in ascending order, rearrange the array into a wave-like array such that: arr[0] ≥ arr[1] ≤ arr[2] ≥ arr[3] ≤ arr[4] ...If multiple wave-like arrangements are possible, find the lexicographically smallest arrangement.Note: The array should be modified in-place.Input: arr[] = [1, 2, 3, 4, 5]Output: [2, 1, 4, 3, 5]Explanation: Array elements after sorting it in the waveform are 2, 1, 4, 3, 5.Input: arr[] = [2, 4, 7, 8, 9, 10]Output: [4, 2, 8, 7, 10, 9]Explanation: Array elements after sorting it in the waveform are 4, 2, 8, 7, 10, 9.Try It YourselfAdjacent Pair Swapping Method - O(n) Time and O(1) O(1) Auxiliary SpaceThe main idea of this approach is to rearrange it into a wave form by swapping adjacent elements in pairs.Since, the elements are in increasing order. Then, by swapping every pair of adjacent elements (i.e., arr[0] with arr[1], arr[2] with arr[3], and so on), we create a pattern where:Every even index i holds a value greater than or equal to its neighboring odd indices i - 1 and i + 1 (if they exist).This guarantees the wave condition: arr[0] ≥ arr[1] ≤ arr[2] ≥ arr[3] ≤ arr[4] ≥ ...The sorted array ensures the numbers are close enough to form valid wave peaks and valleys, and the pairwise swaps are what enforce the pattern.The resulting array is also lexicographically smallest.For the first pair a0 ≤ a1 , the wave condition requires arr[0] ≥ arr[1].So a0 cannot be placed at arr[0]. The smallest possible value is a1 , giving [a1 , a0].The same logic applies to every adjacent pair.Thus, swapping every adjacent pair gives:  [a1, a0, a3 ,a2 , a5 , a4, ...]This arrangement satisfies the wave condition and is the lexicographically smallest valid wave array.
            C++

    #include<iostream>
#include<vector>
#include <algorithm>
using namespace std;

void sortInWave(vector<int> &arr){
    
    int n = arr.size();

    // swap adjacent elements to create 
    // wave pattern
    for (int i = 0; i < n - 1; i += 2){
        swap(arr[i], arr[i + 1]);
    }
}


int main(){
    
    vector<int> arr = {1, 2, 3, 4, 5};
    sortInWave(arr);
    for (int i=0; i<arr.size(); i++)
       cout << arr[i] << " ";
    return 0;
}

void swap(int *x, int *y){
    int temp = *x;
    *x = *y;
    *y = temp;
}

void sortInWave(int arr[], int n){
    
    // swap adjacent elements
