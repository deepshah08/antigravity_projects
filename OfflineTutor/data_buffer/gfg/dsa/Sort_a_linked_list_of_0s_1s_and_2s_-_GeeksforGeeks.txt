# Sort a linked list of 0s, 1s and 2s - GeeksforGeeks

Given a head of linked list containing nodes with values 0, 1, and 2 only, rearrange the list so that all 0s appear first, followed by all 1s, and then all 2s at the end, while maintaining the relative order within each group.Examples:Input:  Output: 0 -> 1  ->1  ->2  ->2  -> 2 -> 2 -> 2Explanation: All the 0s are segregated to the left end of the linked list, 2s to the right end of the list, and 1s in between. Input:  Output: 0 ->1 -> 2 -> 2Explanation: After arranging all the 0s, 1s and 2s in the given format, the output will be 0 -> 1 -> 2 -> 2. Try It YourselfTable of ContentMaintaining Frequency - O(n) Time and O(1) SpaceChanging Links of Nodes - O(n) Time and O(1) SpaceMaintaining Frequency - O(n) Time and O(1) SpaceThe idea is to traverse the linked list and count the occurrences of 0, 1, and 2 using an array cnt[] of size 3. Then, traverse the list again and update the node values by placing all 0s first, followed by 1s and then 2s.cnt[0] stores the count of nodes having value 0.cnt[1] stores the count of nodes having value 1.cnt[2] stores the count of nodes having value 2.
            C++

    #include <iostream>
using namespace std;

class Node
{
  public:
    int data;
    Node *next;

    Node(int new_data)
    {
        data = new_data;
        next = nullptr;
    }
};

Node *segregate(Node *head)
{
    int cnt[3] = {0, 0, 0};
    Node *curr = head;

    // Count occurrences of 0, 1 and 2
    while (curr)
    {
        cnt[curr->data]++;
        curr = curr->next;
    }

    curr = head;
    int idx = 0;

    // Update node values in sorted order
    while (curr)
    {
        if (cnt[idx] == 0)
        {
            idx++;
        }
        else
        {
            curr->data = idx;
            cnt[idx]--;
            curr = curr->next;
        }
    }

    return head;
}

int main()
{

    Node *head = new Node(1);
    head->next = new Node(2);
    head->next->next = new Node(2);
    head->next->next->next = new Node(1);
    head->next->next->next->next = new Node(2);
    head->next->next->next->next->next = new Node(0);
    head->next->next->next->next->next->next = new Node(2);
    head->next->next->next->next->next->next->next = new Node(2);

    head = segregate(head);

    while (head != nullptr)
    {
        cout << head->data;
        if (head->next != nullptr)
        {
            cout << " -> ";
        }
        head = head->next;
    }
    cout << "\n";
    return 0;
}

Changing Links of Nodes - O(n) Time and O(1) SpaceThe idea is to create three separate linked lists for nodes containing 0, 1, and 2, then connect these lists in the required order. This is mainly based on Dutch National Flag algorithm.If the current node's value is 0, append it to the list of 0s and move the zero pointer to the current node.If the current node's value is 1, append it to the list of 1s and move the one pointer to the current node.If the current node's value is 2, append it to the list of 2s and move the two pointer to the current node.Finally, connect the three lists in the order 0, 1, and 2. To avoid handling empty lists separately, use three dummy nodes, zeroD, oneD, and twoD, as the starting points of the lists.
            C++

    #include <iostream>
using namespace std;

class Node
{
  public:
    int data;
    Node *next;

    Node(int new_data)
    {
        data = new_data;
        next = nullptr;
    }
};

Node *segregate(Node *head)
{
    // Create dummy nodes for the three lists.
    Node zeroD(0), oneD(0), twoD(0);
    Node *zero = &zeroD, *one = &oneD, *two = &twoD;

    Node *curr = head;

    // Divide nodes into lists based on their values.
    while (curr)
    {
        Node *nextNode = curr->next;

        if (curr->data == 0)
        {
            zero->next = curr;
            zero = zero->next;
        }
        else if (curr->data == 1)
        {
            one->next = curr;
            one = one->next;
        }
        else
        {
            two->next = curr;
            two = two->next;
        }

        // Move to the next node in the original list.
        curr = nextNode;
    }

    // Connect the three lists in the order 0, 1, and 2.
    zero->next = oneD.next ? oneD.next : twoD.next;
    one->next = twoD.next;
    two->next = nullptr;

    // Return the head of the rearranged list.
    return zeroD.next;
}

int main()
{

    Node *head = new Node(1);
    head->next = new Node(2);
    head->next->next = new Node(2);
    head->next->next->next = new Node(1);
