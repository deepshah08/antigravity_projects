# Word Break - GeeksforGeeks

Given a string s and a list dictionary[] of words. Find whether the string s can be formed by concatenating one or more words from the dictionary[].Note: From dictionary[], any word can be taken any number of times and in any order.Examples:Input: s = "ilike", dictionary[] = ["i", "like", "gfg"]Output: trueExplanation: s can be breakdown as "i like".Input: s = "ilikegfg", dictionary[] = ["i", "like", "man", "india", "gfg"]Output: trueExplanation: s can be breakdown as "i like gfg".Input: s = "ilikemangoes", dictionary[] = ["i", "like", "man", "india", "gfg"]Output: falseExplanation: s cannot be formed using dictionary[] words.Try It YourselfTable of Content[Naive Approach] Trying All Prefixes - O(2^n) Time and O(n) Space[Better Approach 1] Top-Down DP - O(n * m * L) Time and O(n) Space[Better Approach 2] Bottom-Up DP - O(n * m * L) Time and O(n) Space[Expected Approach] Trie and DP - O(n * L + m * L) Time and O(n + m * L) Space[Naive Approach] Trying All Prefixes - O(2^n) Time and O(n) SpaceThe idea is to try every possible prefix of the string. If a prefix is present in the dictionary, we recursively solve for the remaining string. If the remaining string can be broken, the whole string can be broken. Base Case: If the string becomes empty, all its characters have been matched, return true.Working of the Approach:Store all dictionary words in a hash set for O(1) average lookups.If the string is empty, return true, as every character has been matched.For each index i from 1 to n, take the prefix s[0..i).If this prefix is present in the set, recursively check the remaining string s[i..n).If any recursive call returns true, return true immediately.If no prefix leads to a valid break, return false.
            C++

    #include <iostream>
#include <vector>
#include <string>
#include <unordered_set>
using namespace std;

bool wordBreakRec(string s, unordered_set<string> &st) {

    // base case: the whole string is matched
    if (s.empty())
        return true;

    int n = s.length();

    // try every prefix s[0..i)
    for (int i = 1; i <= n; i++) {
        string prefix = s.substr(0, i);

        // if the prefix is a dictionary word, check the remaining string
        if (st.count(prefix) && wordBreakRec(s.substr(i), st))
            return true;
    }

    // no valid break found
    return false;
}

bool wordBreak(string &s, vector<string> &dictionary) {

    // store all dictionary words in a set for fast lookups
    unordered_set<string> st(dictionary.begin(), dictionary.end());

    return wordBreakRec(s, st);
}

int main() {
    string s = "ilike";
    vector<string> dictionary = {"i", "like", "gfg"};

    cout << (wordBreak(s, dictionary) ? "true" : "false") << endl;
    return 0;
}

[Better Approach 1] Top-Down DP - O(n * m * L) Time and O(n) SpaceThe idea is to use memoization on the recursive solution to avoid recomputing the same subproblems. Whether the string can be broken starting from index i depends only on i, so we store this result for every index in a 1D array.  If an index is reached again through a different combination of words, we return the stored result directly instead of recomputing it.Working of the Approach:Create an array dp[] of size n + 1 and initialize it with -1, which means the result is not computed yet.If i is equal to or greater than n, return true, as the whole string is matched.If dp[i] is not -1, return the stored result.Loop through every word of the dictionary and skip it if it is longer than the remaining string.If the word matches the string starting from index i, recursively check the remaining string from index i + word length.If any recursive call returns true, the string can be broken from index i.Store the result in dp[i] and return it.Let us understand with an example:Input: s = "ilike", dictionary = ["i", "like", "gfg"]wordBreakRec(0): "i" matches -> check index 1, "like" and "gfg" do not match at index 0wordBreakRec(1): "like" matches -> check index 5wordBreakRec(5): end of the string -> truedp[1] = true and dp[0] = true, so the answer is true.Why Memoization Helps? We can see overlapping subproblems in the following diagram.  With memoization, each one is solved at most once, which brings the time down from exponential to O(n * m * L).
            C++

    #include <iostream>
#include <vector>
#include <string>
using namespace std;

bool wordBreakRec(int ind, string &s, vector<string> &dictionary, vector<int> &dp) {

    // base case: the whole string is matched
    if (ind >= s.size())
        return true;

    // if the result is already computed, return it
    if (dp[ind] != -1)
        return dp[ind];

    bool possible = false;

    // try every word of the dictionary
    for (int i = 0; i < dictionary.size(); i++) {
        string word = dictionary[i];

        // skip the word if it is longer than the remaining string
        if (word.size() > s.size() - ind)
            continue;

        // check if the word matches the string starting from index ind
        bool ok = true;
        int k = ind;
        for (int j = 0; j < word.size(); j++) {
            if (word[j] != s[k]) {
                ok = false;
                break;
            }
            k++;
        }

        // if it matches, check the remaining string
        if (ok)
            possible |= wordBreakRec(ind + word.size(), s, dictionary, dp);
    }

    // store the result before returning
    return dp[ind] = possible;
}

bool wordBreak(string s, vector<string> &dictionary) {
    int n = s.size();
    vector<int> dp(n + 1, -1);
    return wordBreakRec(0, s, dictionary, dp);
}

int main() {
    string s = "ilike";
    vector<string> dictionary = {"i", "like", "gfg"};

    cout << (wordBreak(s, dictionary) ? "true" : "false") << endl;
    return 0;
}

[Better Approach 2] Bottom-Up DP - O(n * m * L) Time and O(n) Space The idea is to use bottom-up dynamic programming to check if the string can be broken into dictionary words.     #include <iostream>
using namespace std;

bool wordBreak(string &s, vector<string> &dictionary)
{
    int n = s.size();
    vector<bool> dp(n + 1, 0);
    dp[0] = 1;

    // Traverse through the given string
    for (int i = 1; i <= n; i++)
    {

        // Traverse through the dictionary words
        for (string &w : dictionary)
        {

            // Check if current word is present
            // the prefix before the word is also
            // breakable
            int start = i - w.size();
            if (start >= 0 && dp[start] && s.substr(start, w.size()) == w)
            {
                dp[i] = 1;
                break;
            }
        }
    }
    return dp[n];
}

[Expected Approach] Trie and DP - O(n * L + m * L) Time and O(n + m * L) SpaceIn the earlier DP approaches, we compare every word (or every substring) at each position, which costs O(L) per check. The idea is to store all dictionary words in a Trie, so that we can match many words at the same position in a single walk. We do the following after building Trie, We start from index i and move forward character by character, and the walk stops as soon as no word shares the current prefix.  Whenever we reach the end of a word, the position right after it becomes a valid break point.Working of the Approach:Insert all dictionary words into a Trie, and mark the last node of each word as the end of a word.Create a boolean array dp[] of size n + 1, where dp[i] is true if the prefix s[0..i) can be broken into dictionary words.Mark dp[0] = true, as an empty prefix is always valid (base case).For each index i from 0 to n - 1, skip it if dp[i] is false, as no word can start from an unreachable position.If dp[i] is true, start from the root of the Trie and move along the characters s[i], s[i + 1], and so on.If the current character has no child in the Trie, stop, as no dictionary word has this prefix.If the current node marks the end of a word, set dp[j + 1] = true, where j is the index of the current character.At the end, return dp[n].Let us understand with an example:Input: s = "ilike", dictionary = ["i", "like", "gfg"]dp[0] = true, start from index 0 -> 'i' is the end of the word "i" -> dp[1] = true, next 'l' has no child -> stopdp[1] = true, start from index 1 -> l, i, k, e follow the word "like" -> 'e' is the end of a word -> dp[5] = truedp[2], dp[3], dp[4] are false, so they are skippeddp[5] = true, so the answer is true.
            C++

    #include <iostream>
#include <vector>
#include <string>
using namespace std;

// trie node with 26 children, isEnd marks the end of a word
struct TrieNode {
    TrieNode* children[26];
    bool isEnd;

    TrieNode() {
        isEnd = false;
        for (int i = 0; i < 26; i++)
            children[i] = nullptr;
    }
};

// inserts a word into the trie
void insertWord(TrieNode* root, string &word) {
    TrieNode* curr = root;
    for (char c : word) {
        int idx = c - 'a';
        if (curr->children[idx] == nullptr)
            curr->children[idx] = new TrieNode();
        curr = curr->children[idx];
    }
    curr->isEnd = true;
}

bool wordBreak(string &s, vector<string> &dictionary) {
    int n = s.size();

    // insert all dictionary words into the trie
    TrieNode* root = new TrieNode();
    for (string &w : dictionary)
        insertWord(root, w);

    // dp[i] is true if s[0..i) can be broken into dictionary words
    vector<bool> dp(n + 1, false);

    // base case: an empty prefix is always valid
    dp[0] = true;

    // traverse through the given string
    for (int i = 0; i < n; i++) {

        // skip the position if no word can start from it
        if (!dp[i])
            continue;

        // walk down the trie starting from index i
        TrieNode* curr = root;
        for (int j = i; j < n; j++) {
            int idx = s[j] - 'a';

            // stop if no word has this prefix
            if (curr->children[idx] == nullptr)
                break;

            curr = curr->children[idx];

            // if a word ends here, mark the next position as valid
            if (curr->isEnd)
                dp[j + 1] = true;
        }
    }

    // the answer is stored at the last position
    return dp[n];
}

int main() {
    string s = "ilike";
    vector<string> dictionary = {"i", "like", "gfg"};

    cout << (wordBreak(s, dictionary) ? "true" : "false") << endl;
    return 0;
}
