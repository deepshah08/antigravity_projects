# String in Data Structure - GeeksforGeeks

A string is a sequence of characters.  The following facts make string an interesting data structure.Small set of elements. Unlike normal array, strings typically have smaller set of items. For example, lowercase English alphabet has only 26 characters. ASCII has only 256 characters.Strings are immutable in programming languages like Java, Python, JavaScript and C#. Many String Problems can optimized using the fact that the character set size is small.
