# Program for sum of n natural numbers - GeeksforGeeks

Given a positive integer n, find the sum of the first n natural numbers.Examples : Input: n = 3Output: 6Explanation: 1 + 2 + 3 = 6Input: n = 5Output: 15 Explanation:  1 + 2 + 3 + 4 + 5 = 15Try It YourselfTable of Content[Naive Approach] Loop - O(n) Time and O(1) Space[Better Approach] Recursion -O(n) and O(n) Space[Expected Approach] Formula Based Method- O(1) Time and O(1) SpaceSum of Natural Numbers is represented by Triangular Numbers.[Naive Approach] Loop - O(n) Time and O(1) SpaceThe idea is to initialize sum to 0 and iterate from 1 to n, adding each number to sum. After the loop ends, return sum.Consider n = 4Initially : sum = 0i = 1, sum = sum + 1 = 1i = 2, sum = sum + 2 = 3i = 3, sum = sum + 3 = 6i = 4, sum = sum + 4 = 10
            C++

    #include <iostream>
using namespace std;

int findSum(int n){
    int sum = 0;
    
    // iterating over all the numbers 
    // between 1 to n
    for (int i = 1; i <= n; i++)
    {
        sum = sum + i;
    }
    return sum;
}
int main()
{
    int n = 5;
    cout << findSum(n);
    return 0;
}

Output15[Expected Approach] Formula Based Method- O(1) Time and O(1) SpaceThe sum of the first n natural numbers can be calculated directly using the formula: (n * (n+1)) / 2 We can prove this formula using mathematical induction.Base Case:For n = 1,Sum = 1 * (1 + 1) / 2 = 1Thus, the formula holds for (n = 1).Induction Hypothesis:Assume the formula is true for n = k, i.e.,Sum of first k numbers = k * (k + 1) / 2Induction Step:Putting k = n - 1, we getSum of first n - 1 numbers = (n - 1) * n / 2If we add n to this sum, we get,Sum of first n numbers = n + (n - 1) * n / 2= (2n + n2 - n) / 2= n * (n + 1) / 2Hence, the formula is proved.
