# Count digits - GeeksforGeeks

Given a number n, return the count of digits in this number.Example:Input: n = 1567Output: 4Explanation: There are 4 digits in 1567, which are 1, 5, 6 and 7.Input: n = 255Output: 3Explanation: There are 3 digits in 255, which are 2, 5 and 5.Try It YourselfTable of ContentIterative Solution -O(log10(n)) Time or  O(Number of digits) and O(1) Space Using Recursion - O(log10(n)) or  O(Number of digits) Time and O(Number of digits) Space  Using log base 10 function - O(1) Time and O(1) SpaceConverting Number to String - O(Number of digits) Time and O(Number of digits) Space  Iterative Solution -O(log10(n)) Time or  O(Number of digits) and O(1) Space The idea is to count the digits by removing them one by one from the rightmost side (least significant digit) until the number becomes 0.The rightmost digit can be removed easily by performing integer division by 10. Repeat this process and increment the count each time a digit is removed.
            C++

    #include <bits/stdc++.h>
using namespace std;

int countDigits(int n) {
    if (n == 0)
        return 1;

    n = abs(n);
    int count = 0;

    // Remove one digit at a time
    while (n > 0) {
        n /= 10;
        count++;
    }

    return count;
}

int main() {
    int n = 1567;

    cout << countDigits(n);

    return 0;
}

Output4Using Recursion - O(log10(n)) or  O(Number of digits) Time and O(Number of digits) Space  The idea is to remove digits from right by calling a recursive function for each digit. The base condition of this recursive approach is when we divide the number by 10 and the number gets reduced to 0, so return 1 for this operation. If not base case, keep dividing the number by 10 this reduces the input number size by 1 and keeps track of the number of sizes reduced.
            C++

    #include <bits/stdc++.h>
using namespace std;

int countDigits(int n) {
    n = abs(n);

    if (n < 10)
        return 1;

    // Remove one digit and recurse
    return 1 + countDigits(n / 10);
}

int main() {
    int n = 1567;

    cout << countDigits(n);

    return 0;
}

For negative numbers, first take the absolute value of n, since logarithm is not defined for negative values.Digit count of n = floor(log10(n) + 1) 
            C++

    #include <bits/stdc++.h>
using namespace std;

int countDigits(int n) {
    n = abs(n);

    if (n == 0)
        return 1;

    // Log gives the number of digits indirectly
    return floor(log10(n)) + 1;
}
