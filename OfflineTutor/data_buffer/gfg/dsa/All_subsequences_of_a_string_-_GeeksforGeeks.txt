# All subsequences of a string - GeeksforGeeks

Given a string, we have to find out all its subsequences of it. A String is said to be a subsequence of another String, if it can be obtained by deleting 0 or more character without changing its order.For example, sub-sequences of "geeks" are Examples: Input : abOutput : "", "a", "b", "ab"Input : abcOutput : "", "a", "b", "c", "ab", "ac", "bc", "abc"Try It YourselfTable of ContentPick and Don't Pick Recursion - O(n × 2 ^ n) Time and O(n × 2 ^ n) SpaceIncremental - O(n × 2 ^ n) Time and O(n × 2 ^ n) SpaceBinary Representation - O(n × 2 ^ n) Time and O(n × 2 ^ n) SpacePick and Don't Pick Recursion - O(n × 2 ^ n) Time and O(n × 2 ^ n) SpaceWe begin with the last character and for every character, we make two choices, Pick:  make a recursive call for next index and current subsequence appended with the current character.Do Not Pick: make a recursive call for next index and current subsequence as it is.
            C++

    #include <bits/stdc++.h>
using namespace std;

void solve(int i, string &s, string curr, vector<string>& ans) {
    if (i == s.length()) {
        ans.push_back(curr);
        return;
    }

    // Pick the current character
    solve(i + 1, s, curr + s[i], ans);

    // Don't pick the current character
    solve(i + 1, s, curr, ans);
}

vector<string> powerSet(string &s) {
    vector<string> ans;

    solve(0, s, "", ans);

    sort(ans.begin(), ans.end());
    return ans;
}

int main() {
    string s = "abc";

    vector<string> ans = powerSet(s);

    for (string str : ans)
        cout << str << " ";

    return 0;
}

            C++

    #include <bits/stdc++.h>
using namespace std;

vector<string> powerSet(string &s) {
    vector<string> ans = {""};

    for (char ch : s) {
        int size = ans.size();

        // Add current character to existing subsequences
        for (int i = 0; i < size; i++) {
            ans.push_back(ans[i] + ch);
        }
    }

    sort(ans.begin(), ans.end());
    return ans;
}

    for (string str : ans)

    return 0;
}

Treat each number as a bitmaskA set bit means the corresponding character is included in the subsequence and an unset bit means it is skipped.For a string of length n, there are exactly 2ⁿ subsequences. Generate numbers from 0 to 2ⁿ - 1.  Consider each number as a binary representation.  Each bit corresponds to one character. Bit = 1 → include the character. Bit = 0 → skip the character. For "abc":000 → ""001 → "c"010 → "b"011 → "bc"100 → "a"101 → "ac"110 → "ab"111 → "abc"Thus, every possible combination of characters is generated
            C++

    #include <bits/stdc++.h>
using namespace std;

vector<string> powerSet(string &s) {
    int n = s.length();
    vector<string> ans;

    // Generate all possible bitmasks
    for (int mask = 0; mask < (1 << n); mask++) {
        string curr = "";

        // Check each bit
        for (int j = 0; j < n; j++) {
            if (mask & (1 << j))
                curr += s[j];
        }

        ans.push_back(curr);
    }

    sort(ans.begin(), ans.end());
    return ans;
}

int main() {
    string s = "abc";

    vector<string> ans = powerSet(s);

    for (string str : ans)
        cout << str << " ";

    return 0;
}
