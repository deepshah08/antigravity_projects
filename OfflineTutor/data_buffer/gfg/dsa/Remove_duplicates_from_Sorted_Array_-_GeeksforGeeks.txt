# Remove duplicates from Sorted Array - GeeksforGeeks

Given a sorted array arr[] of size n, the goal is to rearrange the array so that all distinct elements appear at the beginning in sorted order. Additionally, return the length of this distinct sorted subarray.Note: The elements after the distinct ones can be in any order and hold any value, as they don't affect the result.Examples: Input: arr[] = [2, 2, 2, 2, 2]Output: [2]Explanation: All the elements are 2, So only keep one instance of 2.Input: arr[] = [1, 2, 2, 3, 4, 4, 4, 5, 5]Output: [1, 2, 3, 4, 5]Input: arr[] = [1, 2, 3]Output: [1, 2, 3]Explanation : No change as all elements are distinct.Try It YourselfTable of Content[Naive Approach] Sorted Set - Works for Unsorted Also - O(n) Time and O(n) Space[Expected Approach] - Single Traversal - O(n) Time and O(1) Space[Naive Approach] Sorted Set - Works for Unsorted Also - O(n) Time and O(n) SpaceTraverse the sorted array and insert each element into a set.A set does not allow duplicate values, so repeated elements are automatically removed.Finally, convert the set into an array/list and return it.
            C++

    #include <iostream>
#include <vector>
#include <set>
using namespace std;

vector<int> removeDuplicates(vector<int>& arr) {
    
    // Put all elements in a sorted set
    set<int> st(arr.begin(), arr.end());
    
    // Put set elements into a result array
    return vector<int>(st.begin(), st.end());
}

int main() {
    vector<int> arr = {1, 2, 2, 3, 4, 4, 4, 5, 5};
    vector<int> uniqueArr = removeDuplicates(arr);
    for (int i = 0; i < uniqueArr.size(); i++) 
        cout << uniqueArr[i] << " ";
    return 0;
}

We mainly need to check if the current element is same as the previous element or not. Step by step implementation:Loop through the array for i = 0 to n-1. At each index i, if arr[i] is different from arr[i-1], add it to the result.After the loop, the result contains the unique element.
            C++

    #include <iostream>
#include <vector>
using namespace std;

vector<int> removeDuplicates(vector<int>& arr) {
    int n = arr.size();
    if (n <= 1)
        return arr;

    // Start from the second element
    int idx = 1;  

    vector<int> result;
    result.push_back(arr[0]);

    for (int i = 1; i < n; i++) {
        if (arr[i]!= arr[i - 1]) {
            result.push_back(arr[i]);
        }
    }
    return result;
}

int main() {
    vector<int> arr = {1, 2, 2, 3, 4, 4, 4, 5, 5};
    vector<int> result = removeDuplicates(arr);
    for (int i = 0; i < result.size(); i++) 
        cout << result[i] << " ";
    return 0;
}
