# Check if a string is substring of another - GeeksforGeeks

Given two strings txt and pat, return the 0-based index of the first occurrence of the substring pat in txt. If pat is not found, return -1.Examples: Input: txt = "GeeksForGeeks", pat = "Fr"Output: -1Explanation: "Fr" is not present in the string "GeeksForGeeks" as substring.Input: txt = "GeeksForGeeks", pat = "For"Output: 5Explanation: "For" is present as substring in "GeeksForGeeks" from index 5 (0 based indexing).Input: txt = "GeeksForGeeks", pat = "gr"Output: -1Explanation: "gr" is not present in the string "GeeksForGeeks" as substring.Try It YourselfTable of ContentNested loops - O(n * m) Time and O(1) SpacePattern Searching Algorithms - O(n + m) TimeIn-built library functionsNested loops - O(n * m) Time and O(1) SpaceThe basic idea is to traverse the string txt and check whether pat matches starting from each index. For every index, use a nested loop to compare the characters of pat with the corresponding characters of txt.If all characters of pat match, return the starting index.If a mismatch occurs, move to the next index of txt.Return -1 if pat is not found in txt.
            C++

    #include <iostream>
using namespace std;

// Function to find if pat is a substring of txt
int firstOccurence(string &txt, string &pat)
{
    int n = txt.length();
    int m = pat.length();

    // Iterate through txt
    for (int i = 0; i <= n - m; i++)
    {

        // Check for substring match
        int j;
        for (j = 0; j < m; j++)
        {

            // Mismatch found
            if (txt[i + j] != pat[j])
            {
                break;
            }
        }

        // If we completed the inner loop, we found a match
        if (j == m)
        {

            // Return starting index
            return i;
        }
    }

    // No match found
    return -1;
}

int main()
{
    string txt = "GeeksForGeeks";
    string pat = "For";

    cout << firstOccurence(txt, pat);

    return 0;
}

    function firstOccurence(txt, pat)
{
    const n = txt.length;
    const m = pat.length;

    // Iterate through txt
    for (let i = 0; i <= n - m; i++) {

        // Check for substring match
        let j;
        for (j = 0; j < m; j++) {

            // Mismatch found
            if (txt[i + j] !== pat[j]) {
                break;
            }
        }

        // If we completed the inner loop, we found a match
        if (j === m) {

            // Return starting index
            return i;
        }
    }

    // No match found
    return -1;
}

int firstOccurence(string &txt, string &pat)
{
    // Find the first occurrence of pat in txt.
    size_t idx = txt.find(pat);

    // Return the index if pat is found, otherwise return -1.
    if (idx != string::npos)
        return idx;

    return -1;
}
