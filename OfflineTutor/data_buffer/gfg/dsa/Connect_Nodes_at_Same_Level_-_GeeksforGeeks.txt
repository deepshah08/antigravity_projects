# Connect Nodes at Same Level - GeeksforGeeks

Given a binary tree, connect each node to its immediate right neighbor at the same level using the nextRight pointer. If no such neighbor exists, set the nextRight pointer to NULL.Examples: Input: root = [1, 2, 3, 4, 5, N, 6] Output: [1, #, 2, 3, #, 4, 5, 6, #]Explanation: The connected tree is: Table of Content[Naive Approach] Level Order Traversal - O(n) Time and O(n) Space[Expected Approach] Using Set Next Rights - O(n) Time and O(1) Space [Naive Approach] Level Order Traversal - O(n) Time and O(n) SpaceThe idea is to traverse the binary tree level by level using a queue and connect adjacent nodes using their nextRight pointers.Insert the root node into the queue.Store the queue size in nodeCount to identify the number of nodes at the current level.Process exactly nodeCount nodes, removing each node from the queue.Set each node's nextRight to the next node at the same level using q.front(). If it is the last node at that level, set nextRight to NULL.Add the left and right children of each node to the queue, if they exist.Repeat until the queue becomes empty.
            C++

    #include <iostream>
using namespace std;

class Node {
public:
    int data;
    Node *left;
    Node *right;
    Node *nextRight;

    Node(int key) {
        data = key;
        left = nullptr;
        right = nullptr;
        nextRight = nullptr;
    }
};

// Connect nodes using node count (level size)
Node* connect(Node *root) {
    if (!root) return root;

    queue<Node*> q;
    q.push(root);

    while (!q.empty()) {
        int nodeCount = q.size();

        for (int i = 0; i < nodeCount; i++) {
            Node* node = q.front();
            q.pop();

            // Set nextRight
            if (i == nodeCount - 1)
                node->nextRight = nullptr;
            else
                node->nextRight = q.front();

            // Push children
            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
    }

    return root;
}

// Print level order using nextRight pointers
void printLevels(Node* root) {
    Node* levelStart = root;

    while (levelStart != nullptr) {
        Node* curr = levelStart;

        while (curr != nullptr) {
            cout << curr->data << " ";
            curr = curr->nextRight;
        }

        cout << "# ";

        // Find the first node of the next level
        if (levelStart->left != nullptr)
            levelStart = levelStart->left;
        else if (levelStart->right != nullptr)
            levelStart = levelStart->right;
        else
            break;
    }
}
int main() {

    // Constructed binary tree
    //       10
    //      /  \
    //    8     2
    //   /     /      
    //  3     4     

    Node *root = new Node(10);
    root->left = new Node(8);
    root->right = new Node(2);
    root->left->left = new Node(3);
    root->right->left = new Node(4);

    connect(root);
    printLevels(root);

    return 0;
}
