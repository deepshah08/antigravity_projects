# N-th root of a number - GeeksforGeeks

Given two integers n and m, find the n-th root of m. The n-th root of m is an integer x such that x^n = m. If no such integer exists, return -1.Examples: Input: n = 3, m = 27Output: 3Explanation: 33 = 27Input: n = 3, m = 9Output: -1Explanation: 3rd root of 9 is not integer.Try It YourselfTable of ContentUsing Binary Search - O(n * log(m)) Time and O(1) SpaceUsing Newton's Method Using Binary Search - O(n * log(m)) Time and O(1) SpaceThe idea is to search within the range from 1 to m. In each step, we do the followingThe middle value is raised to the power of n and compared to m. If it equals m, that value is the root. If it is greater, the search continues in the lower half; if smaller, in the upper half. This process repeats until the root is found or the range is exhausted. If no exact integer root exists, the function returns -1.
            C++

    #include <iostream>
#include <vector>
using namespace std;

// function to calculate base^expo 
// returns early if result exceeds the 
// given limit to avoid overflow
int power(int base, int expo, int limit) {
    int result = 1;
    for (int i = 0; i < expo; i++) {
        result *= base;
        
        if (result > limit)  
            return result;
    }
    return result;
}

// function to find the 
// n-th root of m
int nthRoot(int n, int m) {
    
    // n-th root of 0 is 0
    if (m == 0) return 0;

    // If n is 1, the answer 
    // is m itself
    if (n == 1) return m;

    // binary search to find 
    // the integer root
    int low = 1, high = m;
    while (low <= high) {
        int mid = (low + high) / 2;

        // compute mid^n and compare it with m
        int val = power(mid, n, m);

        if (val == m)
            return mid;  
        else if (val < m)
            low = mid + 1;  
        else
            high = mid - 1; 
    }

    return -1;
}

int main() {
    int n = 3, m = 27;  
    
    int result = nthRoot(n, m);
    cout << result << endl; 

    return 0;
}

Using Newton's Method This problem involves finding the real-valued function A^{1/N}, which can be solved using Newton's method. The method begins with an initial guess and iteratively refines the result.By applying Newton's method, we derive a relation between consecutive iterations:According to Newton's method:\frac{f(x_k)}{f'(x_k)}Here, we define the function f(x) as:f(x) = xN- AThe derivative of f(x), denoted f'(x), is:N\cdot x^{N - 1}The value xk represents the approximation at the k-th iteration. By substituting f(x) and f'(x) into the Newton's method formula, we obtain the following update relation:\frac{1}{N} \left( (N - 1) \cdot x_k + \frac{A}{x_k^{N - 1}} \right)Using this relation, the problem can be solved by iterating over successive values of x until the difference between consecutive iterations is smaller than the desired accuracy.Note: The code below returns the approx value so we use the check to find the if the real nth root is exact.
            C++

    #include <iostream>
#include <cmath>
using namespace std;

bool isExactNthRoot(long long candidate, int n, int m) {
    if (candidate < 0) return false;
    
    long long result = 1;
    for (int i = 0; i < n; i++) {
        // Prevent overflow before multiplying
        if (result > m / candidate) {
            return false;
        }
        result *= candidate;
    }
    return result == m;
}

int nthRoot(int n, int m) {
    // Base edge cases
    if (m == 0) return 0;
    if (m == 1 || n == 1) return m;

    // Initial guess (deterministic, avoiding rand())
    double xPre = (double)m / n;
    if (xPre < 1.0) xPre = 1.0;

    // High precision tolerance
    double eps = 1e-7;
    double delX = 1.0;
    double xK = xPre;

    // Maximum iteration safeguard to avoid infinite loops
    int maxIterations = 1000;
    int iter = 0;

    while (delX > eps && iter < maxIterations) {
        // Newton-Raphson update formula:
        // x_{k+1} = ((n - 1) * x_k + m / (x_k^(n - 1))) / n
        xK = ((n - 1.0) * xPre + (double)m / pow(xPre, n - 1)) / (double)n;
        
        delX = fabs(xK - xPre);
        xPre = xK;
        iter++;
    }

    // Round the converged floating-point value to the nearest integer candidate
    long long rootCandidate = (long long)round(xK);

    // Verify whether rootCandidate^n equals m exactly
    if (isExactNthRoot(rootCandidate, n, m)) {
        return rootCandidate;
    }

    return -1; // Not an exact integer root
}

int main() {
    int n = 3, m = 27;

    int ans = nthRoot(n, m);
    cout << ans << endl; // Output: 3

    return 0;
}

    def isExactNthRoot(candidate: int, n: int, m: int) -> bool:
    """Safely check if candidate ** n == m."""
    if candidate < 0:
        return False
    # In Python, integers have arbitrary precision (no 64-bit overflow)
    return candidate ** n == m


def nthRoot(n: int, m: int) -> int:
    """Find the nth root of m using the Newton-Raphson Method."""
    # Base edge cases
    if m == 0:
        return 0
    if m == 1 or n == 1:
        return m

    # Initial deterministic guess (avoiding random)
    x_pre = float(m) / n
    if x_pre < 1.0:
        x_pre = 1.0

    # High precision tolerance
    eps = 1e-7
    del_x = 1.0
    x_k = x_pre

    # Iteration limit safeguard
    max_iterations = 1000
    iteration = 0

    while del_x > eps and iteration < max_iterations:
        # Newton-Raphson update formula:
        # x_{k+1} = ((n - 1) * x_k + m / (x_k^(n - 1))) / n
        x_k = ((n - 1.0) * x_pre + float(m) / (x_pre ** (n - 1))) / float(n)
        del_x = abs(x_k - x_pre)
        x_pre = x_k
        iteration += 1

    # Round converged value to nearest integer
    root_candidate = round(x_k)

    # Verify if candidate ** n equals m exactly
    if isExactNthRoot(root_candidate, n, m):
        return root_candidate

    return -1

    // BigInt handles exact integer powers of any size
    return (base ** BigInt(n)) === target;
}
