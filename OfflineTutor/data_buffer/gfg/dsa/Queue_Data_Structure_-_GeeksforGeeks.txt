# Queue Data Structure - GeeksforGeeks

A Queue Data Structure follows the principle of "First in, First out" (FIFO), where the first item added to the queue is the first one to be removed. It is used as a buffer in computer systems where we have speed mismatch between two devices that communicate with each other.
