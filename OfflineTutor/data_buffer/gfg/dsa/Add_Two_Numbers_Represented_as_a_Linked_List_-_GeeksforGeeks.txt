# Add Two Numbers Represented as a Linked List - GeeksforGeeks

Given two non-negative integers represented as linked lists with heads head1 and head2, where each node contains a single digit, return a new linked list representing their sum.Note: The input lists may contain leading zeros, but the resulting sum list must not contain any leading zeros.Examples:Input:  Explanation: Sum of 123 and 999 is 1122. Input:  Output: 7 -> 0Explanation: Sum of 63 and 7 is 70. If a list is exhausted, use 0 for its digit.copCreate a new node with sum % 10 and update carry = sum / 10.Append each new node to the result list.If a carry remains, append a node for it.Reverse the result list and remove leading zeros.

// Function to reverse the linked list
Node *reverse(Node *head) {
    Node *prev = nullptr, *curr = head, *next;

    while (curr != nullptr) {
        next = curr->next;
        curr->next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}

	while(head->next != nullptr && head->data == 0)
    	head = head->next;
	return head;
}

        int sum = carry;

        if (num1 != nullptr) {

            num1 = num1->next;
        }

{
    int len = 0;
    while (head)
    {
        len++;
        head = head->next;
    }
    return len;

	while(head->next != nullptr && head->data == 0)
    	head = head->next;
	return head;

// Function to pad shorter list with zeros at front
Node *padList(Node *head, int diff)
{
    while (diff--)
    {
        Node *newNode = new Node(0);
        newNode->next = head;
        head = newNode;
    }
    return head;
}

// Recursive function to add lists
Node *addListRec(Node *num1, Node *num2, int &carry)
{

    if (num1 == nullptr && num2 == nullptr)
        return nullptr;

    // Recurse to the end
    Node *nextNode = addListRec(num1->next, num2->next, carry);

    int sum = num1->data + num2->data + carry;

    Node *curr = new Node(sum % 10);
    carry = sum / 10;

    curr->next = nextNode;

    return curr;
}

// Main function to add two lists
Node *addTwoLists(Node *num1, Node *num2)
{

    int len1 = getLength(num1);
    int len2 = getLength(num2);

    // Pad shorter list
    if (len1 < len2)
        num1 = padList(num1, len2 - len1);
    else
        num2 = padList(num2, len1 - len2);

    int carry = 0;
    Node *result = addListRec(num1, num2, carry);

    // If carry remains, add new node at front
    if (carry)
    {
        Node *newNode = new Node(carry);
        newNode->next = result;
        result = newNode;
    }

    return trimLeadingZeros(result);
}

    head1 = removeLeadingZeros(head1);
    head2 = removeLeadingZeros(head2);

    // Find the lengths of both lists
    int len1 = 0, len2 = 0;

    for (Node* temp = head1; temp != nullptr;
         temp = temp->next)
        len1++;

    for (Node* temp = head2; temp != nullptr;
