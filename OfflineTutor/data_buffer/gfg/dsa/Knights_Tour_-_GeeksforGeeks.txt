# Knight's Tour - GeeksforGeeks

Given an integer n, representing the size of an n × n chessboard. A Knight moves two cells in one direction and one cell perpendicular to that direction. Knight starts at the top-left corner (0, 0) of the board. Your task is to find a valid tour, in which the Knight visits every cell of the board exactly once. Return an n × n matrix in which each cell contains the order in which it is visited. If a valid tour does not exist, return an empty list.  There can be multiple valid tours, you may return any one.Examples:Input: n = 5Output: [[0, 11, 2, 17, 20],[3, 16, 19, 12, 7],[10, 1, 6, 21, 18],[15, 4, 23, 8, 13],[24, 9, 14, 5, 22]]Explanation: A possible knight's tour in a 5 x 5 chessboard is given above where each number represents the step at which the Knight visits that cell, starting from (0, 0) as step 0.Input: n = 4Output: []Explanation: For n = 4, no sequence of knight moves can visit all 16 cells exactly once, starting from the top-left cell. Hence, the answer is an empty array [].Try It YourselfTable of ContentRecursion + Backtracking - O(8^(n * n)) Time and O(n^2) Space Warnsdorff's Algorithm - O(8^(n * n))  Time and O(n^2) Space Recursion + Backtracking - O(8^(n * n)) Time and O(n^2) Space The idea is to use recursion and backtracking to find a knight's tour that visits every cell exactly once. Start at (0, 0), mark it as 0, and try all 8 possible knight moves from the current cell. If a move leads to a dead end, undo it (backtrack) and try another move. Stop when all n*n cells are visited or no valid tour exists.Initialize an n × n board with -1 and mark the top-left cell as 0.Define the eight possible moves of a knight using dx and dy arrays.At each step, try all eight possible knight moves from the current cell.If a move is within bounds and visits an unvisited cell, mark it with the current step number.Recursively continue from the new cell. If the path fails, backtrack by resetting the cell to -1.If all n² cells are visited, return the board; if no valid tour exists, return an empty array.

int dy[8] = {1, 2, 2, 1, -1, -2, -2, -1};

// move is valid
bool isSafe(int x, int y, int n, vector<vector<int>> &board)
{
    return (x >= 0 && y >= 0 && x < n && y < n && board[x][y] == -1);
}

// Recursive function to solve Knight's Tour
bool knightTourUtil(int x, int y, int step, int n, vector<vector<int>> &board)
{
    // If all squares are visited
    if (step == n * n)
    {
        return true;
    }

    // Try all 8 possible knight moves
    for (int i = 0; i < 8; i++)
    {
        int nx = x + dx[i];
        int ny = y + dy[i];

        {
            board[nx][ny] = step;

            if (knightTourUtil(nx, ny, step + 1, n, board))
            {
                return true;
            }

            // Backtrack
            board[nx][ny] = -1;
        }
    }

    return false;
}

Warnsdorff's Algorithm - O(8^(n * n))  Time and O(n^2) Space Backtracking works but is inefficient because it explores many unnecessary paths. If the correct move happens to be the last option, the algorithm wastes time trying all the wrong ones first.Warnsdorff’s Algorithm uses a heuristic to reduce backtracking. Instead of trying moves in random order, it always chooses the next move with the fewest onward moves (the cell with the smallest degree). Illustration: Initialize an n × n board with -1 and mark the top-left cell as 0.From the current cell, find all valid moves to unvisited cells.For each valid move, count the number of unvisited cells the knight can move to next.Sort the valid moves in ascending order of their onward-move counts.Try the moves in sorted order, recursively continuing the tour and backtracking if a move leads to failure.If all n*n cells are visited, return the completed board; otherwise, return an empty array if no tour is found.

}

// Recursive function to solve the Knight's Tour
function knightTourUtil(x, y, step, n, board, dir)
{
    if (step === n * n)
        return true;

    const moves = getSortedMoves(board, x, y, dir);

    for (const move of moves) {
        const dirIdx = move[1];
        const nx = x + dir[dirIdx][0];
        const ny = y + dir[dirIdx][1];

        board[nx][ny] = step;

        if (knightTourUtil(nx, ny, step + 1, n, board, dir))
            return true;

        // Backtrack
        board[nx][ny] = -1;
    }

    return false;
}

// Function to start Knight's Tour
function knightTour(n)
{
    // Define 8 knight moves
    const dir = [
        [ 2, 1 ], [ 1, 2 ], [ -1, 2 ], [ -2, 1 ],
        [ -2, -1 ], [ -1, -2 ], [ 1, -2 ], [ 2, -1 ]
    ];

    const board
        = Array.from({length : n}, () => Array(n).fill(-1));

    // Start from top-left corner
    board[0][0] = 0;

    if (knightTourUtil(0, 0, 1, n, board, dir))
        return board;

    return [];
}
