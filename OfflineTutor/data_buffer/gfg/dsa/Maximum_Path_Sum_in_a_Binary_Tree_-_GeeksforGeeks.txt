# Maximum Path Sum in a Binary Tree - GeeksforGeeks

Given the root of a binary tree, find the maximum path sum. The path may start and end at any node in the tree.Examples: Input: root[] = [10, 2, 10, 20, 1, N, -25, N, N, N, N, 3, 4]Output: 42Explanation: Max path sum is represented using green colored nodes in the above binary tree. Input: root[] = [-17, 11, 4, 20, -2, 10] Output: 31Explanation: Max path sum is represented using green colored nodes in the above binary tree.Try It YourselfTable of Content[Naive Approach] Downward Paths for Every Node - O(n ^ 2) Time and O(h) Space[Expected Approach] Single Postorder DFS - O(n) Time and O(h) Space[Naive Approach] Downward Paths for Every Node - O(n ^ 2) Time and O(h) SpaceThe idea is to treat every node as the turning point of the path and compute the best downward path from its left and right subtrees. The maximum answer is the largest path found among all nodes.Working of Approach:Visit each node and find the maximum downward sum from its left and right subtrees using maxDown().Ignore negative sums by taking max(0, sum) before using them.Calculate the path passing through the current node and compare it with the best answers from the left and right subtrees.Return the maximum path found among the current node, left subtree, and right subtree.
            C++

    #include <iostream>
using namespace std;

class Node
{
  public:
    int data;
    Node *left;
    Node *right;

    Node(int val)
    {
        data = val;
        left = right = nullptr;
    }
};

// Returns the maximum sum from root to any descendant.
int maxDown(Node *root)
{
    if (root == nullptr)
        return 0;

    int left = max(0, maxDown(root->left));
    int right = max(0, maxDown(root->right));

    return root->data + max(left, right);
}

int findMaxSum(Node *root)
{
    if (root == nullptr)
        return INT_MIN;

    int left = max(0, maxDown(root->left));
    int right = max(0, maxDown(root->right));

    int throughRoot = root->data + left + right;

    return max({throughRoot, findMaxSum(root->left), findMaxSum(root->right)});
}

int main()
{

    // Representation of input binary tree:
    //            10
    //           /  \
    //          2    10
    //         / \     \  
    //        20  1    -25
    //                 /  \
  	//				  3	   4
    Node *root = new Node(10);
    root->left = new Node(2);
    root->right = new Node(10);
    root->left->left = new Node(20);
    root->left->right = new Node(1);
    root->right->right = new Node(-25);
    root->right->right->left = new Node(3);
    root->right->right->right = new Node(4);

    cout << findMaxSum(root);
    return 0;
}

Output42Note: This approach recomputes the maximum downward path for the same subtrees multiple times. As a result, it takes O(n ^ 2) time in the worst case (especially for skewed trees) and may lead to TLE for large inputs.[Expected Approach] Single Postorder DFS - O(n) Time and O(h) SpaceThe idea is to use postorder traversal. At each node, calculate left and right path sums, and update a global maximum with (left + node + right). Return the node’s value plus the larger side upward. The global maximum at the end gives the answer.Why This Works?The maximum path in the tree must pass through some node as its highest (turning) point. During the traversal, each node is treated as this turning point and the path sum through it is computed. The answer is updated whenever a larger path is found, while only the best downward path is returned to the parent so that the path remains continuous.Working of Approach:Traverse the binary tree using postorder recursion so that the left and right subtree results are available before processing the current node.For every node, compute the maximum downward path sum from its left and right child, ignoring negative contributions using max(0, pathSum).Update res with the maximum path sum passing through the current node as left + right + root->data.Return root->data + max(left, right) so that only one branch can be extended to the parent.After the traversal completes, res stores the maximum path sum between any two nodes in the binary tree.Let us understand with an example:Input: root[] = [10, 2, 10, 20, 1, N, -25, N, N, N, N, 3, 4]Start the postorder traversal from the root and first process the left and right subtrees recursively.At node 2, the left contribution is 20 and the right contribution is 1, so res becomes 20 + 2 + 1 = 23, and 22 is returned to its parent.At node -25, the best downward contributions are 3 and 4, so the path sum is 3 + (-25) + 4 = -18. The value -21 is returned upward.At the root 10, the left contribution is 22 and the right contribution is 10, giving the path sum 22 + 10 + 10 = 42. Update res = 42.After the traversal completes, res = 42, which is the maximum path sum in the binary tree.

    #include <iostream>
using namespace std;

class Node
{
  public:
    int data;
    Node *left, *right;

    // Constructor to initialize a new node
    Node(int value)
    {
        data = value;
        left = right = nullptr;
    }
};

// Returns the maximum path
// sum in the subtree with the current node as an endpoint.
int findMaxSumRec(Node *root, int &res)
{

    if (root == NULL)
        return 0;

    // Calculate maximum path sums for left and right subtrees
    int l = max(0, findMaxSumRec(root->left, res));
    int r = max(0, findMaxSumRec(root->right, res));

    // Update 'res' with the maximum path
    // sum passing through the current node
    res = max(res, l + r + root->data);

    return root->data + max(l, r);
}

// Returns maximum path sum in tree with given root
int findMaxSum(Node *root)
{
    int res = root->data;

    // Compute maximum path sum and store it in 'res'
    findMaxSumRec(root, res);

    return res;
}

int main()
{

    // Representation of input binary tree:
    //            10
    //           /  \
    //          2    10
    //         / \     \  
    //        20  1    -25
    //                 /  \
  	//				  3	   4
    Node *root = new Node(10);
    root->left = new Node(2);
    root->right = new Node(10);
    root->left->left = new Node(20);
    root->left->right = new Node(1);
