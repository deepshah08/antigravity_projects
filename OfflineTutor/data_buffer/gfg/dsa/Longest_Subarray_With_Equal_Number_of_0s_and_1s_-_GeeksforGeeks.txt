# Longest Subarray With Equal Number of 0s and 1s - GeeksforGeeks

Given an array arr[] of 0s and 1s. Find and return the length of the longest subarray with equal number of 0s and 1s.Examples: Input: arr[] = [1, 0, 1, 1, 1, 0, 0]Output: 6Explanation: arr[1...6] is the longest subarray with three 0s and three 1s.Input: arr[] = [0, 0, 1, 1, 0]Output: 4Explanation: arr[0...3] or arr[1...4] is the longest subarray with two 0s and two 1s.Input: arr[] = [0]Output: 0Explanation: There is no subarray with an equal number of 0s and 1s.Try It YourselfTable of Content[Naive Approach] Nested Loop - O(n ^ 2) Time and O(1) Space[Expected Approach] Hash Map andPrefix Sum - O(n) Time and O(n) Space[Naive Approach] Nested Loop - O(n ^ 2) Time and O(1) SpaceThe idea is to generate all possible subarrays and check whether the subarray has equal number of 0s and 1s or not.Working of Approach:Iterate through every possible starting index s and consider all subarrays starting from that index.Traverse each subarray and treat 0 as -1 and 1 as +1 while maintaining their cumulative sum.If a subarray contains an equal number of 0s and 1s, its converted sum becomes 0.Whenever sum is 0, update res with the maximum length of the valid subarray found so far.After checking all possible subarrays, return res as the maximum length.
            C++

    #include <iostream>
#include <vector>
using namespace std;

int maxLen(vector<int> &arr)
{
    int res = 0;

    // Pick a starting point as 's'
    for (int s = 0; s < arr.size(); s++)
    {
        int sum = 0;

        // Consider all subarrays arr[s...e]
        for (int e = s; e < arr.size(); e++)
        {
            sum += (arr[e] == 0) ? -1 : 1;

            // Check if it's a 0-sum subarray
            if (sum == 0)

                // update max size
                res = max(res, e - s + 1);
        }
    }
    return res;
}

int main()
{
    vector<int> arr = {1, 0, 1, 1, 1, 0, 0};
    cout << maxLen(arr);
}

Store 1 -> 0 in the HashMap.At index 1, the element is 0, so preSum = 0. Update res = 2 because the subarray [1, 0] contains an equal number of 0s and 1s.As we continue traversing, whenever a prefix sum repeats, the elements between its previous occurrence and the current index have a sum of 0.At index 6, preSum = 1, which was first seen at index 0. Therefore, the length of the subarray is 6 - 0 = 6, so update res = 6.After traversing the array, the maximum length obtained is 6, corresponding to the subarray [0, 1, 1, 1, 0, 0].
            C++

    #include <iostream>
#include <unordered_map>
#include <vector>
using namespace std;

int maxLen(vector<int> &arr)
{
    unordered_map<int, int> mp;

    int preSum = 0;
    int res = 0;

    // Traverse through the given array
    for (int i = 0; i < arr.size(); i++)
    {
        // Add current element to sum
        // if current element is zero, add -1
        preSum += (arr[i] == 0) ? -1 : 1;

        // If prefix sum is 0, the subarray from index 0 to i
        // has an equal number of 0s and 1s
        if (preSum == 0)
            res = i + 1;

        // If this sum is seen before, then update
        // result with maximum
        if (mp.find(preSum) != mp.end())
            res = max(res, i - mp[preSum]);

        // Else put this sum in hash table
        else
            mp[preSum] = i;
    }

    return res;
}

{
    vector<int> arr = {1, 0, 1, 1, 1, 0, 0};

    cout << maxLen(arr) << endl;
    return 0;
}


            C

    #include <stdio.h>

#define MAX_SIZE 1000

int maxLen(int arr[], int n)
{
    int firstIndex[2 * MAX_SIZE + 1];

    for (int i = 0; i <= 2 * n; i++)
        firstIndex[i] = -1;

    int preSum = 0;
    int res = 0;
    int offset = n;

    // Traverse through the given array
    for (int i = 0; i < n; i++)
    {
        // Treat 0 as -1 and 1 as +1
        preSum += (arr[i] == 0) ? -1 : 1;

        // If prefix sum is 0, subarray from 0 to i is valid
        if (preSum == 0)
        {
            res = i + 1;
        }

        // If this sum is seen before, update result
        else if (firstIndex[preSum + offset] != -1)
        {
            int len = i - firstIndex[preSum + offset];
            if (len > res)
                res = len;
        }
        else
        {
            // Store the first occurrence of the prefix sum
            firstIndex[preSum + offset] = i;
        }
    }

    return res;
}

    import java.util.HashMap;

class GFG {
    static int maxLen(int[] arr)
    {
        HashMap<Integer, Integer> mp = new HashMap<>();

        int preSum = 0;
        int res = 0;

        // Traverse through the given array
        for (int i = 0; i < arr.length; i++) {

            // Add current element to sum
            // if current element is zero, add -1
            preSum += (arr[i] == 0) ? -1 : 1;

            // To handle sum = 0 at last index
            if (preSum == 0)
                res = i + 1;

            // If this sum is seen before, then update
            // result with maximum
            if (mp.containsKey(preSum))
                res = Math.max(res, i - mp.get(preSum));

            // Else put this sum in hash table
            else
                mp.put(preSum, i);
        }

        return res;
    }

    public static void main(String[] args)
    {
        int[] arr = { 1, 0, 1, 1, 1, 0, 0 };

        System.out.println(maxLen(arr));
    }
}
